# Советник моделей — model-advisor

Пользовательский skill для Codex, который перед новой содержательной задачей предлагает конкретную модель и уровень рассуждения, кратко объясняет выбор и при наличии обоснованного варианта называет альтернативу с меньшим предполагаемым расходом ресурсов.

Skill помогает выбрать начальную конфигурацию работы. Для выполнения задачи требуется ручное подтверждение; настройки модели он самостоятельно не переключает.

## Возможности

- Учитывает ясность требований, зависимости, сложность проверки и последствия ошибки.
- Для простых задач сначала рассматривает подходящую конфигурацию с меньшим расходом ресурсов, без универсального предпочтения одной модели.
- Объясняет конкретный компромисс альтернативы по требованиям задачи.
- Для важных результатов напоминает о проверке, включая актуальные первичные источники, когда они нужны.
- После «продолжай» переходит к исходной задаче без повторного цикла подбора.

## Состав

```text
model-advisor/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── README.md
```

`SKILL.md` содержит инструкции и датированную справку моделей. `agents/openai.yaml` задаёт имя и стартовый запрос в интерфейсе. Отдельных исполняемых скриптов и серверных зависимостей в пакете нет.

## Установка

Нужен клиент Codex с поддержкой локальных skills. Это самостоятельный skill, а не готовый плагин для всех интерфейсов ChatGPT.

1. Скачайте репозиторий и назовите папку `model-advisor`.
2. Поместите её в пользовательский каталог skills так, чтобы инструкции находились по адресу `~/.agents/skills/model-advisor/SKILL.md`, а метаданные — в `~/.agents/skills/model-advisor/agents/openai.yaml`.
3. Если такой skill уже установлен, сначала сохраните отдельную резервную копию и проверьте различия; не перезаписывайте свою версию без проверки.
4. Убедитесь, что `model-advisor` появился в списке skills. Codex обычно обнаруживает изменения автоматически; если skill не появился, перезапустите клиент.

Для установки только в проект можно использовать `.agents/skills/model-advisor` в соответствующем репозитории. Поддерживаемые расположения и способы распространения описаны в [официальной документации skills](https://learn.chatgpt.com/docs/build-skills).

## Использование

Вызовите skill явно и опишите задачу:

```text
$model-advisor
Нужен план небольшого сайта выставки: программа, участники и схема проезда. Один человек обновляет материалы раз в месяц; регистрации и оплаты нет.
```

В ответе должны появиться точное имя модели, один уровень рассуждения и причина по задаче. Если обоснован более лёгкий вариант, skill объяснит его компромисс. Когда полезная альтернатива не установлена, он может её не предлагать.

При желании выберите рекомендованные настройки вручную, затем напишите:

```text
продолжай
```

Исходная задача выполняется на текущих настройках чата. Само подтверждение не означает, что модель была переключена.

Чтобы выполнить задачу сразу, используйте явный обход:

```text
Без подбора модели, сразу составь план.
```

При продолжении уже подтверждённой работы повторная рекомендация обычно не нужна. Простые разговорные вопросы и короткие правки обычно пропускаются, если подбор не запрошен явно.

## Основания выбора и актуальность

Выбор основан на описании задачи, видимом контексте и качественных правилах. Числового рейтинга, полного сравнения моделей на новой задаче и автоматического определения оптимальной конфигурации нет.

В `SKILL.md` включена резервная справка от **2 ноября 2026 года**, основанная на [OpenAI Models](https://learn.chatgpt.com/docs/models). Имена моделей, их доступность, поддерживаемые уровни и условия использования могут изменяться. Более свежие надёжные сведения, уже доступные в контексте, имеют приоритет. Названия Low и Light зависят от клиента; одинаковые названия уровней разных моделей не означают одинаковый расход.

Skill не читает меню моделей динамически и не получает актуальные тарифы автоматически. Наличие модели в API или каталоге другого инструмента не доказывает её доступность в основном чате.

## Ограничения

- Конкретная рекомендация остаётся оценкой отвечающей модели и может различаться между запусками и моделями-советниками.
- Качество, точность, отсутствие ошибок, время выполнения и экономия не гарантируются. Более высокий уровень рассуждения не заменяет проверку результата.
- Отдельный совет тоже расходует ресурсы. Совокупная экономия от использования skill не установлена.
- Автоматический вызов зависит от клиента и его инструкций. Для предсказуемого использования вызывайте `$model-advisor` явно.
- Более приоритетные правила среды сохраняют силу: skill не может гарантированно убрать обязательные служебные пояснения или цитаты.
- Публичного воспроизводимого сравнительного бенчмарка и автоматических тестов в этом репозитории нет. Локальные наблюдения не доказывают превосходство одной конфигурации на всех задачах.
